## How to use it in another ChatGPT account

1. Open the Markdown file above.
2. Copy its contents, or provide the link to the file.
3. In the other ChatGPT account, send this instruction:

   > Read the OpenAI API Overview reference in this repository: https://github.com/admragy/ai/blob/main/docs/openai-api-overview.md . Use it as a source for our discussion. When details may have changed, verify them against the official documentation: https://developers.openai.com/api/reference/overview.md .

A GitHub link does not automatically import a file into another ChatGPT account's memory or conversation. The other account must open or provide the file in its own chat.
